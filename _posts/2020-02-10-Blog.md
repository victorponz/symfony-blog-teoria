La única parte que tiene nueva es el concepto de `slug`. Por ejemplo, si creo un post con el siguiente título `título del post` creará un slug así [http://127.0.0.1:8080/single_post/titulo-del-post](http://127.0.0.1:8080/single_post/titulo-del-post). Es decir lo hace SEO Friendly, eliminando caracteres extraños y interponiendo `-` entre palabras . Usar el slugger es tan fácil como **inyectar la dependencia** en el controlador: `SluggerInterface $slugger`

Según [https://www.noticias.ltda/online-marketing/sito-web/slug-seo/](https://www.noticias.ltda/online-marketing/sito-web/slug-seo/)

> -info-Si creas sitios web y, por ende, practicas el SEO, seguramente has  escuchado la palabra **slug**. Esta palabra define la parte final de la URL  que identifica una página dentro de un sitio web. En pocas palabras,  debes verla como la parte de la URL que resume el contenido de la página en una o más palabras clave. Debes saber y aprender cómo optimizar el  slug porque este juega un papel importante: es leído por los motores de  búsqueda y entendido por los usuarios.

#[Route('/single_post/{slug}', name: 'single_post')]
public function post(ManagerRegistry $doctrine, Request $request, $slug): Response
{
    $repository = $doctrine->getRepository(Post::class);
    $post = $repository->findOneBy(["slug"=>$slug]);
    $recents = $repository->findRecents();
    $comment = new Comment();
    $form = $this->createForm(CommentFormType::class, $comment);
    $form->handleRequest($request);
    if ($form->isSubmitted() && $form->isValid()) {
        $comment = $form->getData();
        $comment->setPost($post);  
        //Aumentamos en 1 el número de comentarios del post
        $post->setNumComments($post->getNumComments() + 1);
        $entityManager = $doctrine->getManager();    
        $entityManager->persist($comment);
        $entityManager->flush();
        return $this->redirectToRoute('single_post', ["slug" => $post->getSlug()]);
    }
    return $this->render('blog/single_post.html.twig', [
        'post' => $post,
        'recents' => $recents,
        'commentForm' => $form->createView()
    ]);
}

## 5.8 Paginar los resultados

Para poder paginar hemos de conocer los siguientes datos:

1. La consulta a realizar
2. Cuántos resultados devuelve la misma
3. En qué pagina estamos
4. Cuántos elementos *caben* en cada página  (ventana)

> Por ejemplo, tenemos 20 posts y una ventana de 5, tenemos un total de 4 páginas. Si estamos en la página 1, devolverá del 0 al 4

Ahora modificamos el método del repositorio para que haga uso del paginador integrado de Doctrine:

```php
use Doctrine\ORM\Tools\Pagination\Paginator;
/**
 * Devuelve un Paginator con los posts de la página indicada.
 * El Paginator es iterable (posts de la página) y count()
 * devuelve el número TOTAL de posts de la consulta.
 * $perPage Es el tamaño de la ventana y $page es la página actual, que empieza en 1
 */
public function findPaginados(int $page, int $perPage): Paginator
{
    $query = $this->createQueryBuilder('p')
        ->orderBy('p.PublishedAt', 'DESC')
        ->setFirstResult(($page - 1) * $perPage)
        ->setMaxResults($perPage)
        ->getQuery();

    return new Paginator($query, false);
}

/**
 * Página $page de los posts cuyo contenido contiene $searchTerm.
 * count() sobre el resultado devuelve el total de coincidencias.
 */
public function findBuscadosPaginados(string $searchTerm, int $page, int $perPage): Paginator
{
    $query = $this->createQueryBuilder('p')
        ->andWhere('p.Content LIKE :val')
        ->setParameter('val', '%'.$searchTerm.'%')
        ->orderBy('p.PublishedAt', 'DESC')
        ->setFirstResult(($page - 1) * $perPage)
        ->setMaxResults($perPage)
        ->getQuery();

    return new Paginator($query, false);
}
```
Modificamos los controladores para que hagan uso de este nuevo método
```php
private const POSTS_PER_PAGE = 5; //Ponlo a 1 para pruebas

#[Route('/blog/{page}', name: 'blog')]
public function index(ManagerRegistry $doctrine, int $page = 1): Response
{
    $page = max(1, $page);

    $repository = $doctrine->getRepository(Post::class);
    //Aquí obtenemos los datos con el método creado en el repositorio
    $posts = $repository->findPaginados($page, self::POSTS_PER_PAGE);
    $recents = $repository->findRecents();

    $total = count($posts);
    $totalPages = max(1, (int) ceil($total / self::POSTS_PER_PAGE));

    // Si piden una página que no existe, redirigimos a la última
    if ($page > $totalPages) {
        return $this->redirectToRoute('blog', ['page' => $totalPages]);
    }

    return $this->render('blog/blog.html.twig', [
        'posts' => $posts,
        'recents' => $recents,
        'page'       => $page,
        'totalPages' => $totalPages,
        'total'        => $total,
    ]);
}

#[Route('/blog/buscar/{page}', name: 'blog_buscar')]
public function buscar(ManagerRegistry $doctrine, Request $request, int $page = 1): Response
{
    $page = max(1, $page);

    $repository = $doctrine->getRepository(Post::class);
    $searchTerm = $request->query->get('searchTerm', '');
    $posts = $repository->findBuscadosPaginados($searchTerm, $page, self::POSTS_PER_PAGE);
    $recents = $repository->findRecents();

    $total = count($posts);
    $totalPages = max(1, (int) ceil($total / self::POSTS_PER_PAGE));

    // Si piden una página que no existe, redirigimos a la última (conservando la búsqueda)
    if ($page > $totalPages) {
        return $this->redirectToRoute('blog_buscar', ['page' => $totalPages, 'searchTerm' => $searchTerm]);
    }

    return $this->render('blog/blog.html.twig', [
        'posts'      => $posts,
        'recents'    => $recents,
        'searchTerm' => $searchTerm,
        'page'       => $page,
        'totalPages' => $totalPages,
        'total'      => $total,
    ]);
}
```

    Paginador reutilizable.
    Parámetros:
      - page:          página actual
      - totalPages:    número total de páginas
      - ruta:          nombre de la ruta, que debe aceptar el parámetro "page"

#}

{% set ventana = ventana|default(2) %}

    {% set hasta = min(totalPages, page + ventana) %}

    <nav class="pager" aria-label="Paginación de posts">
        <ul class="pagination">

            {# Anterior #}
            {% if page > 1 %}

            {% endif %}

            {% if desde > 1 %}
                <li><a href="{{ path(ruta, parametros|merge({'page': 1})) }}" aria-label="Página 1">1</a></li>
                {% if desde > 2 %}
                    <li class="pager-gap" aria-hidden="true"><span>&hellip;</span></li>
                {% endif %}
            {% endif %}

            {# Puntos suspensivos y última página #}
            {% if hasta < totalPages %}
                {% if hasta < totalPages - 1 %}

            {% if page < totalPages %}

                    <span aria-disabled="true"><span class="pager-label">Siguiente</span><i class="fa fa-arrow-right"></i></span>
                </li>

## 5.9 Me gusta

En este apartado veremos cómo implementar el botón `Like`.

Crearemos la ruta `/single_post/{slug}/like`

```php
#[Route('/single_post/{slug}/like', name: 'post_like')]
public function like(ManagerRegistry $doctrine, $slug): Response
{
    $repository = $doctrine->getRepository(Post::class);
    $post = $repository->findOneBy(["slug"=>$slug]);
    if ($post){
        // Haz un método llamado like() en la entidad Post que aumente en 1 numLikes
        $post->like();
        $entityManager = $doctrine->getManager();    
        $entityManager->persist($post);
        $entityManager->flush();
    }
    return $this->redirectToRoute('single_post', ["slug" => $post->getSlug()]);

}
```

## 5.11 Buscar entradas

Vamos a implementar un buscador.

![image-20220401090554057](/symfony-blog-teoria/assets/img/blog/image-20220401090554057.png)

**Repositorio de posts**

```php
/**
* @return Post[] Returns an array of Post objects
*/
public function findByText(string $searchTerm): array
{
    return $this->createQueryBuilder('p')
        ->andWhere("p.content LIKE :val")
        ->setParameter('val', '%'.$searchTerm.'%')
        ->orderBy('p.publishedAt', 'DESC')
        ->getQuery()
        ->getResult();

}
```

En este caso estamos usando un parámetro llamado `val` al que le fijamos el valor `'%'.$searchTerm.'%'` lo que convertirá la consulta en:

```sql
SELECT * FROM POSTS WHERE CONTENT LIKE = '%searchTerm%'
```

**Controlador**

```php
#[Route('/blog/buscar', name: 'blog_buscar')]
public function buscar(ManagerRegistry $doctrine,  Request $request): Response
{
    $repository = $doctrine->getRepository(Post::class);
    $searchTerm = $request->query->get('searchTerm', '');
    $posts = $repository->findByText($searchTerm);
    $recents = $repository->findRecents();
    return $this->render('blog/blog.html.twig', [
        'posts' => $posts,
        'recents' => $recents,
        'searchTerm' => $searchTerm
    ]);
}
```

Cuando se pulsa el botón `buscar`, se genera la siguiente petición: [http://127.0.0.1:8080/blog/buscar?searchTerm=texto](http://127.0.0.1:8080/blog/buscar?searchTerm=texto). Fíjate que en la url aparece un `queryString`:`searchTerm=texto`. Pues bien, para acceder a dicho parámetro desde un controlador usamos :
```php
$searchTerm = $request->query->get('searchTerm', '');
```
